# Aeman Sajid — Compact Moodboard Portfolio

## Run locally
1. Extract this ZIP.
2. Open this folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**, or double-click `index.html`.

## Included
- Compact cinematic blue/violet hero based on the supplied moodboard
- Second portrait (`portrait.jpg`)
- Full-width glossy desk foreground with tech books and coffee mug
- Rounded, clickable navigation and hero buttons
- About, skills, projects, experience, recognition, research, education and contact sections

Google Fonts requires an internet connection. Replace placeholder social URLs in `index.html` with your exact profile links before publishing.
